Fox Run

  • Game Boy Color
  • Assembly
  • 160 × 144 pixels
  • Student team

Set the engine aside and face the hardware of 1998: a complete, playable Game Boy Color game written in assembly. A fox runs across the snowfield, jumps, and opens its mouth to catch what the road brings. The whole ROM is 436 KB, the emulator lives right in the page, and clicking is playing.

RoleBuilt with fellow students — assembly code, pixel art

TechGame Boy assembly · Aseprite

SizeOne 436 KB file · zero loading · best with a keyboard

  • Reused graphic assets to keep the whole game inside the Game Boy's ROM budget
  • Assembled the fox from 20 sprite tiles, with macros to batch-sync their coordinate updates
  • Studied the GBC's expanded memory architecture and palette system to pull color out of 1998 hardware
